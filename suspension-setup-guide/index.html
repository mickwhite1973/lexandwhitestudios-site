PLAIN-ENGLISH SETUP

Measure. Adjust. Test. Save.

The guide is designed around repeatable workshop and road-test steps rather than unexplained numbers.

1

Save the bike once

Add the motorcycle, Spyder, trike or specialty suspension and identify the fitted adjusters.

2

Set SAG first

Use wheel travel and consistent measuring points. Correct SAG with preload, not damping clickers.

3

Fine-tune one symptom

Choose the clearest ride problem, change one control by one small step, then repeat the same test.

4

Keep the result

Better settings update the bike. Every before-and-after test remains available in Test History.

PRIVACY FIRST

Your garage belongs to you.

Suspension Setup Guide does not require an account for the current release. Vehicle profiles, measurements, clicker positions, notes and test history are stored locally on your device.

Export and import tools can be used for user-controlled backup. A future optional account system may add device syncing, but local use will remain the foundation of the guide.

WHERE THIS CAN GO NEXT

Built for riders, with room to grow.

Future Lex & White Rider Tools could include optional cloud sync, verified manufacturer reference material, shared community setups and motorcycle-focused sponsors. The core setup tool will stay focused on measured, repeatable suspension work.
