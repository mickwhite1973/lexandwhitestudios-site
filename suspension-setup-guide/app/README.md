# Suspension Setup Guide — Version 1.4

Version 1.4 turns the main search box into **Search My Garage & App**.

## What it searches

### My Garage
- saved motorcycles, Spyders, trikes and other vehicle profiles
- make, model and year
- shock/fork brand and model
- current rear SAG, preload, compression, rebound, LSC and HSC
- current front SAG, preload, compression and rebound
- saved notes
- Test History
- symptoms, riding goals and Better/Worse/Unchanged test results

### App Help & Tools
- Complete Vehicle Setup
- Guided SAG
- adjuster identification
- SAG calculator
- compression/rebound fine-tuning
- symptoms
- safe adjustment method
- units and other built-in app sections

## Search behaviour

Search is entirely local. It does **not** query the public web.

Examples:
- `Spyder rebound`
- `Wilbers`
- `potholes`
- `plush`
- `33%`
- `pack down`

Garage matches appear first. Relevant app-help sections appear underneath.

All Version 1.3 functionality remains, including wheel-travel clarification,
twin-front SAG comparison, one-vehicle storage and full damping guidance.
